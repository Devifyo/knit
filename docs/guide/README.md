# Knit CRM — User Guide

Welcome to Knit. This guide explains **how to use every part of the app**, in plain
language, step by step. You don't need to be technical — each page tells you *what
a feature is for*, *where to click*, and *exactly what happens* when you do.

> **New here?** Start with **[Getting Started](01-getting-started.md)**. It walks you
> through signing up, logging in, and finding your way around. Then come back to this
> page and jump to whatever you need.

---

## How this guide is organised

Each guide follows the same simple shape so you always know where to look:

- **What it's for** — one line, in plain English.
- **Where to find it** — the exact menu/button to click.
- **Step by step** — numbered instructions for the main tasks.
- **Field reference** — every field in a form, what it means, and whether it's required.
- **Tips & gotchas** — the things that confuse people, explained up front.
- **Who can use it** — which team roles see the feature (see [Team & Roles](14-team-and-roles.md)).

## A few words that show up everywhere

| Word | What it means in Knit |
|---|---|
| **Workspace** | Your company's private area in Knit. All your data is isolated to it. |
| **Owner / Admin / Manager / Agent** | The four roles that control who can see and do what. See [Team & Roles](14-team-and-roles.md). |
| **Contact** | A person you do business with. |
| **Company** | An organisation a contact belongs to. |
| **Lead** | A potential customer you haven't qualified yet. |
| **Deal** | A sales opportunity moving through your pipeline. |
| **Pipeline / Stage** | The columns your deals move through (New → … → Won/Lost). |
| **Pixel / token** | Invisible markers in marketing emails that let Knit count opens and clicks. |

> If a button described in this guide isn't visible to you, it's almost always because
> your **role** doesn't include that permission. Ask an Owner or Admin — see
> [Team & Roles](14-team-and-roles.md).
